Toronto Crime Dashboard

Interactive dashboard exploring Toronto neighbourhood crime data from 2014 to 2025. I cleaned the data, ranked neighbourhoods by crime type and rate, charted 12-year trends, and compared crime types and how they changed over time. The Streamlit app has filters for crime type and year, plus a neighbourhood search with a per-area breakdown.

Impact of COVID-19 on NBA Game Outcomes

Analyzed 10,000+ NBA games (2012 to 2024) to see how COVID-19 affected game outcomes and home-court advantage. I cleaned the data and engineered features like home/away classification, COVID indicators and margin categories. I built and compared linear regression models that predict point differential from shooting efficiency and game location, picked the best one using a train/validation/test split and RMSE, and charted the relationships with ggplot2.

  • R
  • ggplot2
  • Linear regression
  • Feature engineering
